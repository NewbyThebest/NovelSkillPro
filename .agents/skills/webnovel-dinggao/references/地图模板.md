# 地图与空间事实

## 维护边界

- **事实截止**：第[最新定稿章号]章《[标题]》定稿后。
- **用途**：记录已定稿正文中可跨章复用的区域层级、稳定地点、连通关系、相对方向、通行条件与空间限制。
- **事实规则**：只写定稿正文已经确认的空间事实。角色猜测、未验证出口和用途不明区域必须放入“未确认空间”，不得自行补成客观地图。
- **收录门槛**：只收录会影响后续转场、追逐、潜入、搜索、战斗地形或权限判断的稳定事实；一次性站位、临时摆设、逐步走位和纯气氛环境不入账。
- **职责边界**：人物当前位置写入进度和角色状态；本章移动过程写入章纲与正文；移动耗时写入时间线；本文件只保存稳定空间结构。
- **方向规则**：没有正文依据时不补东南西北。左、右、前、后必须注明行进参照；参照不明时只记录“相连”。
