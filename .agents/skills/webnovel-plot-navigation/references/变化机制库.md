# 变化机制库

本库为场景提供阻力、升级与转折。每章或每个场景素材优先选一个主要阻力，原策略需要改向时再选一个转折；多章路线须逐章配置，不能用整条路线的主导机制代替各章展开，也不能为制造热闹全部叠加。

## 阻力来源

| 编号 | 来源 | 关键问题 | 使用边界 |
| :--- | :--- | :--- | :--- |
| R01 | 对手利益 | 谁会因主角成功而实际受损？ | 不能只因讨厌主角而阻拦 |
| R02 | 盟友利益 | 帮忙会让盟友失去什么或违背什么？ | 盟友不能无理由刁难 |
| R03 | 目标人物意愿 | 被救、被说服或被安排的人自己想怎样？ | 不能把对方写成任务物品 |
| R04 | 制度规则 | 哪条既有流程、资格、礼法或权限挡路？ | 规则不能临时新增 |
| R05 | 资源不足 | 缺什么具体材料、钱、时间、人手或体力？ | 稀缺必须真实且有用途 |
| R06 | 时间压力 | 什么窗口会自然关闭？ | 时限不能随意伸缩 |
| R07 | 空间环境 | 地形、天气、距离、封闭或人群怎样限制行动？ | 环境必须影响选择而非装饰 |
| R08 | 身体状态 | 伤势、疲劳、疾病或能力代价怎样改变方案？ | 不能临场新增限制 |
| R09 | 心理创伤 | 恐惧、羞耻、执念或误解怎样阻止人物？ | 用具体反应和选择表现 |
| R10 | 认知不足 | 人物缺哪条信息或持有什么合理误判？ | 不能靠作者藏关键常识 |
| R11 | 技能门槛 | 哪一步需要人物尚未掌握的技术？ | 不能一练即会或突然全能 |
| R12 | 身份风险 | 采取行动会暴露什么身份、关系或违规？ | 暴露后必须有后果 |
| R13 | 职责冲突 | 岗位、承诺或家庭责任与当前目标怎样冲突？ | 两边都要对人物有价值 |
| R14 | 团队分歧 | 成员对目标、方法、风险或分工哪里不同？ | 不能靠拒绝沟通硬拖 |
| R15 | 协作失配 | 能力、节奏、信息或信号无法配合在哪里？ | 失败应暴露具体协作问题 |
| R16 | 群体惯性 | 传统、舆论、恐慌或从众怎样妨碍行动？ | 群体不能集体降智 |
| R17 | 技术故障 | 工具、系统、装置或制作流程哪里会失败？ | 故障要有前兆或常理依据 |
| R18 | 道德底线 | 有效方法会伤害谁、违背什么原则？ | 不能制造一眼可解的假两难 |
| R19 | 信息冲突 | 两份都可信的信息为何不能同时成立？ | 必须给读者判断依据 |
| R20 | 成功代价 | 达成目标会顺带触发什么责任、关注或损失？ | 代价应由成功本身引起 |

## 升级方式

| 编号 | 升级 | 变化方式 |
| :--- | :--- | :--- |
| U01 | 门槛抬高 | 原本所需条件增加，但原因来自对方反应或环境变化 |
| U02 | 窗口缩短 | 时间、机会或耐心比预期更少 |
| U03 | 资源递减 | 每次尝试都消耗不可立即补充的东西 |
| U04 | 目标移动 | 人、物、地点或需求发生合理变化 |
| U05 | 对方适应 | 对手根据主角已用手段调整 |
| U06 | 旁人卷入 | 主角选择开始影响无辜者、盟友或群体 |
| U07 | 责任增加 | 取得越多，必须保护、解释或管理的越多 |
| U08 | 选项关闭 | 一个安全办法被证明确实不可用 |
| U09 | 代价前置 | 原以为以后支付的代价现在便到账 |
| U10 | 信息增多反而矛盾 | 新线索使原判断更难成立 |
| U11 | 内外压力耦合 | 解决外部问题会加重身体、关系或秘密风险 |
| U12 | 目标分裂 | 原本单一目标拆成两个无法同时完成的目标 |
| U13 | 方法被公开 | 私下手段进入他人视野，失去隐蔽优势 |
| U14 | 盟友降低投入 | 合作者因自身风险缩减帮助，而非突然背叛 |
| U15 | 小问题触发制度 | 局部行动惊动更正式的流程或更高权限者 |
| U16 | 环境状态改变 | 天黑、断电、封路、拥挤、天气或秩序改变 |

## 转折机制

转折要让原策略失效或改变目标含义，不等于随便揭露一个秘密。

| 编号 | 转折 | 原策略为何改变 |
| :--- | :--- | :--- |
| T01 | 目标真实需求不同 | 主角争取的并非对方真正需要的东西 |
| T02 | 成功条件被误解 | 达成表面指标不等于解决问题 |
| T03 | 阻碍者其实在止损 | 对方阻拦背后有主角尚未知的合理风险 |
| T04 | 帮助附带不可接受条件 | 最便利的解法触碰底线或更重要目标 |
| T05 | 证据指向自己人 | 调查结果迫使主角重新评估关系 |
| T06 | 目标主动拒绝 | 被帮助者基于自己的利益不配合 |
| T07 | 对手先一步完成 | 原计划失去对象，只能争后果或换目标 |
| T08 | 第三方改变归属 | 成果、责任或信息落到另一方手中 |
| T09 | 旧方法产生反效果 | 熟悉手段加剧问题，且原因符合既有规则 |
| T10 | 成功过头 | 主角得到超出预期的关注、资源、责任或伤害 |
| T11 | 失败反而开路 | 原目标落空，却暴露更适合的入口或真相 |
| T12 | 代价落到别人身上 | 主角发现继续行动将由他人承担损失 |
| T13 | 时间表突然提前 | 已有事件因合理触发提前，不是作者强推 |
| T14 | 环境使规则反转 | 同一能力、身份或计划在新条件下意义改变 |
| T15 | 盟友改变优先级 | 新事实让盟友按自己的目标重新选择 |
| T16 | 对手目标不是阻止 | 对手其实想利用、测试、招揽或逼主角表态 |
| T17 | 任务对象发生互换 | 求助者变成帮助者、猎物变诱饵、考官反被考察 |
| T18 | 选择本身会公开立场 | 无论选哪边，人物都无法继续保持暧昧位置 |
| T19 | 取得物无法直接使用 | 资源、证据、能力或资格还缺解释、保护或承载条件 |
| T20 | 局部答案改写旧事件 | 新解释让人物此前合理行动产生另一层后果 |
| T21 | 共同敌人暂时消失 | 原联盟失去基础，内部利益立刻显现 |
| T22 | 主角主动改目标 | 人物发现原目标不值得其代价，选择保另一项 |
| T23 | 最弱环节来自内部 | 失败源不是强敌，而是分工、流程或认知漏洞 |
| T24 | 公开评价与事实相反 | 群体把成功当失败或把失败当成功，迫使人物应对 |

## 选择结构

| 编号 | 结构 | 两边代价 |
| :--- | :--- | :--- |
| D01 | 保人还是保成果 | 救人失去机会；保成果承担关系或道德后果 |
| D02 | 公开还是隐瞒 | 公开失去安全；隐瞒失去信任或时机 |
| D03 | 守约还是止损 | 守约承担现实损失；止损伤害信誉或关系 |
| D04 | 眼前回报还是长期空间 | 现在拿到好处；未来受控或透支 |
| D05 | 独自承担还是寻求帮助 | 保住秘密；或分担风险但交出筹码 |
| D06 | 按规则还是违规 | 安全但可能失败；破局但留下追责证据 |
| D07 | 相信谁 | 两方证据都不完整，选择会改变关系 |
| D08 | 继续尝试还是承认上限 | 冒险争取成功；或保全状态但失去窗口 |
| D09 | 完成任务还是尊重对象 | 履行委托；或接受当事人的不同选择 |
| D10 | 维持联盟还是坚持底线 | 合作继续但自损；或关系破裂承担外敌压力 |
| D11 | 个人目标还是群体责任 | 保住自己的机会；或承担公共损失 |
| D12 | 追答案还是先处理后果 | 获得真相但放任危机；或先止损让线索冷却 |

## 使用规则

- 阻力来源必须在正文、设定或人物利益中有依据。
- 升级优先改变条件，不只增加人数、战力与倒计时。
- 转折必须影响人物的策略、目标或选择；只增加惊讶不算转折。
- 一个场景可以没有大转折，但必须有结果；安静场景可用认知、关系或新常态变化收住。
- 近期连续使用同一阻力或转折时降低优先级，即使换了人物和地点也视为重复。
