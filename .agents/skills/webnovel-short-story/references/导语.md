# 短篇导语

## 输入与目标

读取短篇方向大纲、主推标题和必要设定。导语是成稿最前面的阅读入口，不是简介，也不应重复正文已经写出的整段内容。

## 写法

- 默认 80-150 字，用户指定长度优先。
- 第一行给出具体事件、压力、异常、关系问题或结果，不慢铺背景。
- 让读者看清主角处境和核心问题；身份反差、特殊底牌或关系标签只有实际存在时才写。
- 结尾给继续阅读的理由：未解问题、选择代价、反击预期或情绪悬念。不要剧透最终结算。

## 输出

默认给 1 个主版本；只有冲突直给与悬念保留等方向存在明显取舍时，再补 1-2 个备选。确认后写入 `4-正文/导语.md`。

该文件只放导语正文本身：**不写 `# 导语` 之类的标题行，不写“主推导语”“备选导语”等标注，不写任何标签**。需要留备选时另存草稿，不写进该文件。导语属于正文，但不并入任何一章正文文件，由 `webnovel-short-story` 第 9 步合并成稿时置顶。

导语写入后，按与章节正文相同的标准跑强制校准：

```bash
python "<WORKSPACE_ROOT>/.agents/skills/webnovel-zhengwen/scripts/check_sentence_linebreaks.py" --fix "<WORKSPACE_ROOT>/4-正文/导语.md"
python "<WORKSPACE_ROOT>/.agents/skills/webnovel-zhengwen/scripts/fix_quotes.py" --fix "<WORKSPACE_ROOT>/4-正文/导语.md"
```

两句都要跑：换行脚本必须显式传入文件路径，不会自动扫目录；标点脚本虽然能扫全目录，但导语改动后仍需对导语本身确认一次。
