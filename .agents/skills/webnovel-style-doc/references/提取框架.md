# 提取框架

读参照作品原文时，用来判断"它是什么样的文风"的角度。**跨作品通用**——换哪本书都用这一套，只是每本填出来的答案不同。

**适用于有叙述者的叙事作品。** 书信体、日记体、剧本体、意识流等叙述者本身多元或消解的体裁，本框架不适用。

**读不出来就跳过，不要硬套。不要逐条填，不要写读书笔记。** 这一页是备查的，不是任务清单。

**读出来的东西只用来判断这本书的文风。** 结论留在你脑子里，**不进文档**——写作时去读原文就有，写成条目反而会让写作者照着条目凑。

---

## 一、谁在看，谁在说

**这两件事要分开。** 有时用第三人称讲，但只让你看一个人看到的东西；有时谁都能看，但说话的人只有一个。

| 维度 | 选项 |
| :--- | :--- |
| 人称 | 第一人称／第三人称／混合 |
| 叙述者位置 | 故事内（参与者）／故事外（旁观者） |
| 可靠性 | 可靠／不可靠／部分不可靠 |
| 介入程度 | 沉默记录／适度评论／强介入（可说教、可插话） |
| 知道多少 | 只写外部行为／写判断／写完整思想与情绪 |

**看聚焦**：说得比人物知道的多（全知）、只说某个人知道的（有限）、说得比人物还少（客观）。三种都对，看作者选哪种。

**看距离**：从站在远处报道，到贴进人物皮肉里，是一条连续的线。同一段里可以在线上移动——作者怎么移动、移多远，就是他的做法。

**看越界**：说出在场人物不可能知道的旧事、后事，叫多给；省略该视角本应提供的信息，叫少给。反复出现的越界就是做法——记它往哪个方向越、越到什么程度；只见到一次的，不必判断它是做法还是失手。

**看对人物的态度**：俯视、同情、还是平视？这是叙述者的立场，贯穿全书。

## 二、句子之间有没有一个"说话的人"

有些文风里句子只是句子，没有人在讲；有些文风里，你能听见一个声音在补话、插话、评一句。两种都常见。

- 句子和句子之间，有没有不提供信息、只提供口气的衔接？
- 有没有说完一件事之后多一句评论或调侃？
- 有没有"据说""听来的说法是"这类转述口吻？

**答案是"没有"也是答案。** 极简、白描的作品里叙述者就是不出现，照实记即可。

## 三、他习惯做什么

同一件事，不同的作者会有不同的处理。这里看的是"他选了哪种处理"，不是"他写得好不好"。

- 会不会停下来讲一段来历？什么时机讲、讲多长？
- 会不会把人物的推理一步步摊开给读者看？哪些场合摊开、哪些场合只给结果？
- 会不会在叙述中间插话、评论、替读者下个判断？
- 会不会写进人物心里？写多深、写多久、什么时机进出？

## 四、哪些是常态、哪些是偶然

只读几十章，很容易把某几章的特点误当全书形态。扫一遍全书，看那个写法出现多少次、是贯穿全书还是只在几章里，用来校正你自己的判断。

**这一步的结论留在你脑子里。** 它是为了让你在判断这本书的文风时不至于读偏。
