# 伏笔追踪表

## 使用规则

**伏笔的定义**：正文中已经写下的、指向未来才会揭晓的可验证线索。它必须同时满足三条：

1. 正文实写了这件事，不是作者的规划或角色的猜测；
2. 它是明确的谜团、阴谋、机制暗线或未决危机；
3. 它现在无法被读者自行回答，需要后续正文给出答案。

**不算伏笔、不得写入本表的**：

- 人物之间的信任建立、感情变化、日常对话与关系推进；
- 已经交代清楚的事实，以及读者当场就能推断出结论的写法；
- 角色的常规反应、神态、态度等一次性描写；
- 情绪起伏、状态描述与生活细节。

**本表只有一张待收回表。** 伏笔一旦收回，直接从本表删除，不移入“已收回”表——收回之后它已经是定稿正文与章纲里的既成事实，留着只会让本表无限增长。需要回查某条旧伏笔在哪一章收回，去看对应章纲。

**备注列只写事实边界**：这条伏笔在正文里写到了哪一步、还差什么没交代、复用时不得自行补什么。不写角色做了什么、说了什么、过程如何——那些是定稿正文和章纲的内容。备注控制在两句话以内。
