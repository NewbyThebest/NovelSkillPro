# 地图与空间事实

## 维护边界

- **事实截止**：第[最新定稿章号]章《[标题]》定稿后。
- **用途**：记录已定稿正文中可跨章复用的区域层级、稳定地点、已确认连通关系、相对方向与通行条件。
- **事实规则**：只写定稿正文已经确认的空间事实。角色猜测、未验证出口和用途不明区域不写入本文件，等正文确认后再补入。
- **收录门槛**：只收录会影响后续转场、追逐、潜入、搜索、战斗地形或权限判断的稳定空间事实。比赛规则、判定与扣分、系统播报、身份等级、作息安排、环境描写，以及人物去向与人物反应一律不写入本文件——它们分别属于设定案、章纲、角色状态与总账。
- **不做推演**：只写“这里是什么、怎么通、有什么拦着”，不写“因此会怎样”。影响与后果留给章纲和正文判断，本文件不为它们单列。
- **职责边界**：人物当前位置写入进度和角色状态；本章移动过程写入章纲与正文；移动耗时写入时间线；本文件只保存稳定空间结构。
- **方向规则**：没有正文依据时不补东南西北。左、右、前、后必须注明行进参照；参照不明时只记录“相连”。
