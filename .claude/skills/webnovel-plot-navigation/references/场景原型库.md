# 场景原型库

场景原型是承载变化的具体场合，不是固定桥段。先按本轮主功能筛选，再用本书已有的人物、地点、规则与资源填充。不能由原型反向扩大推进尺度。

## 使用规则

- 场景原型先服从人物行动，再服从题材外观。没有人会合理进入该场合时淘汰。
- 一章可包含多个场景，但只保留一个主功能；其余场景服务主变化。
- 同一原型连续使用时，更换阻力、转折或结果不一定足够；近期疲劳明显时直接换原型族。
- 安静场景同样需要局部目标与结果，但不必硬塞外敌、打脸或大节点。
