# 通用网文套路池

本池保存可跨作品迁移的因果机制，不保存具体作品桥段。检索时先看“解决功能”和“前置条件”，再看套路名。每次优先使用一个主套路，必要时叠加一个辅套路。

字段说明：

- **解决**：适合处理的剧情缺口。
- **前置**：本书中已经存在才可使用的条件。
- **骨架**：把槽位替换为本书人物、利益和规则后的因果结构。
- **回报**：主要读者体验。
- **出口**：使用后可自然产生的后续。
- **失效**：应淘汰或谨慎使用的情况。

## 一、让主角重新动起来

### A01 欠账催行动
- **解决**：主角没有眼前目标，剧情停在等待状态。
- **前置**：主角已经许诺、借债、欠人情、隐瞒事实或留下未完成责任。
- **骨架**：旧承诺到期或被人追问 -> 逃避成本上升 -> 主角必须兑现、协商或违约 -> 选择暴露其优先级。
- **回报**：人物可信、旧线回响、现实压力。
- **出口**：兑现引出新关系；违约造成信任裂缝；偿还发现更大问题。
- **失效**：此前没有明确欠账；追债者只是作者传话工具。

### A02 损失倒逼止损
- **解决**：阶段目标太远，主角不知道下一步做什么。
- **前置**：主角已有资源、位置、关系或安全边界可失去。
- **骨架**：现有成果开始流失 -> 主角发现损失仍会扩大 -> 选择保哪一项、舍哪一项 -> 止损行动形成近端任务。
- **回报**：紧迫、选择压力、主角主动性。
- **出口**：保住核心但暴露弱点；牺牲次要资源换取时间；找出损失来源。
- **失效**：损失可轻易恢复；受损事物对主角没有实际价值。

### A03 机会窗口关闭
- **解决**：目标存在但行动没有时限。
- **前置**：已有名额、交易、路线、比赛、资源成熟期、人物离开等有限机会。
- **骨架**：机会出现并即将关闭 -> 多方同时行动 -> 主角必须提前下注 -> 选择改变后续站位。
- **回报**：倒计时、竞争、期待。
- **出口**：抢到机会后承担门槛；失败转向替代路线；竞争者结仇或结盟。
- **失效**：时限可以随意延长；机会由临时设定凭空出现。

### A04 主动验证判断
- **解决**：信息很多但剧情只停留在猜测。
- **前置**：主角已有一个可验证的怀疑、规则理解或人物判断。
- **骨架**：主角设计低成本试探 -> 对方或规则给出异常反馈 -> 判断部分成立、部分被推翻 -> 主角调整目标。
- **回报**：智力参与、信息推进、人物能力展示。
- **出口**：试探惊动对方；发现更深层规则；错误判断带来代价。
- **失效**：试探结果由作者随意决定；主角没有能力想到该验证方式。

### A05 抢先布局
- **解决**：主角总在被动接招。
- **前置**：主角掌握对手尚不知道的信息、时间差、资源或行为规律。
- **骨架**：主角预判对方下一步 -> 提前布置一个可回收动作 -> 对方照常行动 -> 布局改变交锋条件。
- **回报**：掌控感、期待后续兑现。
- **出口**：对方发现布局后升级；布局只成功一半；辅线人物被卷入。
- **失效**：信息优势没在前文建立；主角突然全知全能。

### A06 自设小目标
- **解决**：宏大阶段目标无法直接转成场景。
- **前置**：阶段缺口可以拆成一次获取、接触、确认、说服或脱身行动。
- **骨架**：主角把大目标拆成一个可验证结果 -> 选择最先解决的阻碍 -> 本章完成或失败 -> 获得下一步依据。
- **回报**：清晰推进、获得感。
- **出口**：小目标成功却暴露更大困难；失败提供必要信息；完成后升级任务。
- **失效**：小目标与阶段结果没有因果关系；完成与否都不影响局面。

## 二、激活阻力与竞争

### B01 利益撞车
- **解决**：主角目标明确，但没人真正阻碍。
- **前置**：至少另一方需要同一资源、名额、人物支持、位置或时间窗口。
- **骨架**：双方目标在同一点互斥 -> 对方先占优势 -> 主角选择竞价、交换、破局或换规则 -> 胜负改变资源与关系。
- **回报**：竞争、爽感、地位变化。
- **出口**：败者反制；胜者支付额外代价；第三方借机入场。
- **失效**：对方只为针对主角而争；资源其实足够所有人使用。

### B02 规则门槛
- **解决**：取得目标过于轻松。
- **前置**：已有制度、资格、礼法、等级、通关条件或组织流程。
- **骨架**：主角抵达目标前发现硬门槛 -> 常规路径被堵 -> 利用规则、补足资格或承担违规风险 -> 规则的另一面被揭示。
- **回报**：破局、能力展示、世界真实感。
- **出口**：取得临时资格；得罪守门人；发现规则被人操纵。
- **失效**：门槛临时新增只为拖延；规则可被主角一句话无视。

### B03 第三方截胡
- **解决**：两方对抗走向过于可预测。
- **前置**：已有第三方能从双方争斗中获利，并具备行动条件。
- **骨架**：主角与对手互相牵制 -> 第三方夺走成果或改变条件 -> 原敌我关系被迫重估 -> 主角决定追击、合作或止损。
- **回报**：意外、局势扩展。
- **出口**：临时同盟；三方竞争；幕后利益浮现。
- **失效**：第三方此前毫无痕迹；截胡只是强行让主角失败。

### B04 盟友条件加码
- **解决**：帮助来得太容易，关系没有拉力。
- **前置**：主角需要已有角色的资源或支持，对方有独立利益。
- **骨架**：主角求助或合作 -> 对方提出与自身利益一致的条件 -> 主角在代价间选择 -> 同盟成立但埋下边界。
- **回报**：关系博弈、人物立体、现实感。
- **出口**：条件日后到期；双方目标暂时一致后分叉；主角寻找替代筹码。
- **失效**：盟友条件纯为刁难；条件与其利益无关。

### B05 对手合理升级
- **解决**：旧对手已被压制，冲突失去张力。
- **前置**：对手从此前失败中获得了信息、资源、盟友或权限。
- **骨架**：对手复盘失败原因 -> 针对主角已暴露手段调整策略 -> 主角旧办法失效 -> 必须改变打法。
- **回报**：强敌感、成长压力。
- **出口**：主角开发新手段；对手内部出现分歧；冲突升到更高层面。
- **失效**：对手无成本突然变强；升级只是战力数字增加。

### B06 内外压力夹击
- **解决**：单线压力不足，选择不够难。
- **前置**：主角已有一个外部目标和一个内部关系、资源或身体限制。
- **骨架**：外部威胁要求立即行动 -> 内部问题限制可选方案 -> 主角只能保一头或设计兼顾方案 -> 代价落地。
- **回报**：紧张、两难、人物选择。
- **出口**：被暂缓的一线恶化；兼顾方案留下隐患；关系因选择改变。
- **失效**：两个压力互不影响；所有问题都被主角轻松解决。

## 三、推进信息与悬念

### C01 旧线索换解释
- **解决**：伏笔久拖或线索没有推进。
- **前置**：已有异常、物件、证词、行为或规则痕迹。
- **骨架**：旧线索在新场景中再次出现 -> 新信息改变其含义 -> 主角修正判断 -> 旧问题变成更具体的新问题。
- **回报**：前后呼应、恍然感、好奇。
- **出口**：锁定嫌疑范围；旧盟友变得可疑；发现线索被人为布置。
- **失效**：新解释否定此前全部证据；答案来自临时新增信息。

### C02 半真相到账
- **解决**：谜团长期只有提问，没有阶段回报。
- **前置**：谜团可拆成身份、原因、方法、目的或后果等层次。
- **骨架**：主角获得一个可验证答案 -> 答案解决旧疑问 -> 同时暴露更深层缺口 -> 行动目标随之改变。
- **回报**：解谜满足、新悬念。
- **出口**：追查答案来源；利用半真相反制；错误理解造成风险。
- **失效**：所谓半真相只是模糊提示；每次回答都无限套娃。

### C03 证词互相冲突
- **解决**：信息推进平直，没有判断空间。
- **前置**：两个已有角色对同一事件有不同利益、视角或认知。
- **骨架**：双方提供不能同时成立的信息 -> 主角寻找可验证差异 -> 冲突暴露谎言、误判或第三种事实 -> 关系重新排序。
- **回报**：参与推理、人物张力。
- **出口**：说谎者反制；误判者承担后果；第三方证据出现。
- **失效**：冲突只靠某人忘记常识；作者不给读者任何判断依据。

### C04 信息落到错误的人手里
- **解决**：秘密存在但没有产生后果。
- **前置**：已有秘密、证据或关键消息，以及会利用它的人。
- **骨架**：信息因主角行动、疏漏或他人布局转移 -> 获得者据此行动 -> 主角发现局势已变 -> 必须补救或反用泄露。
- **回报**：紧张、因果回收。
- **出口**：舆论或追捕；假情报反制；秘密持有者提出交易。
- **失效**：泄密纯靠巧合偷听；获得者行为不符合利益。

### C05 可控误导
- **解决**：对手太容易看穿主角计划。
- **前置**：主角知道对手会观察什么，并有能力展示部分真相。
- **骨架**：主角故意暴露真实但不完整的信息 -> 对手据此作出合理误判 -> 主角利用其选择 -> 误导成本或暴露风险随后出现。
- **回报**：智斗、反转。
- **出口**：对手识破一半；盟友也被误导；假象必须继续维护。
- **失效**：主角无法预测对手信息来源；反转靠隐瞒读者已经应当知道的主角计划。

### C06 秘密逼近公开
- **解决**：隐藏身份、关系或违规行为长期不产生压力。
- **前置**：秘密已存在，公开后会改变资源、关系、地位或安全。
- **骨架**：一个既有证据进入公开链条 -> 多方开始接近真相 -> 主角决定掩盖、抢先承认或转移焦点 -> 秘密状态发生变化。
- **回报**：紧张、身份期待、关系考验。
- **出口**：局部曝光；知情者交易；主动揭露反而夺回话语权。
- **失效**：秘密公开没有后果；证据凭空出现。

## 四、推动关系变化

### D01 被迫同盟
- **解决**：关系停滞，双方没有必须接触的理由。
- **前置**：两人存在共同威胁、互补资源或暂时一致的目标，同时保留利益分歧。
- **骨架**：单独行动都会失败 -> 双方交换有限筹码 -> 合作中暴露能力与边界 -> 成功或失败改变信任。
- **回报**：关系拉扯、配合爽感。
- **出口**：联盟到期；一方隐瞒代价；共同成果归属引发冲突。
- **失效**：共同目标不够紧迫；一方完全不需要另一方。

### D02 立场公开
- **解决**：角色长期暧昧站位，关系没有结果。
- **前置**：已有公开场合、阵营压力或不可回避的选择。
- **骨架**：局面要求角色当众表态或行动 -> 选择支持、反对或中立 -> 立即失去一部分关系或利益 -> 新站位成立。
- **回报**：关系兑现、阵营清晰、情绪爆点。
- **出口**：被支持者欠下人情；旧阵营反扑；私下关系与公开立场冲突。
- **失效**：选择没有代价；角色突然改变立场且无铺垫。

### D03 价值观冲突落地
- **解决**：人物差异只停留在嘴上。
- **前置**：双方对同一具体利益、风险或人物有不同优先级。
- **骨架**：事件迫使双方同时决定 -> 不同价值观导向不同动作 -> 结果证明各有得失 -> 关系留下真实裂缝或理解。
- **回报**：人物深度、关系张力。
- **出口**：暂时分道；一方承担另一方选择的后果；日后重新评价。
- **失效**：争论没有行动后果；一方被写成纯粹错误。

### D04 互换筹码
- **解决**：合作或情感推进缺少可见行为。
- **前置**：双方各自掌握对方需要且愿意有限交付的资源、信息或风险承担。
- **骨架**：双方先试探底线 -> 各交出一部分筹码 -> 一方先履约或先承担风险 -> 信任或戒心发生变化。
- **回报**：成熟关系、博弈感、信任兑现。
- **出口**：筹码价值不对等；履约引来外部风险；交换暴露真实需求。
- **失效**：所谓筹码对对方无价值；交换只是送礼。

### D05 误会以证据推进
- **解决**：关系误会停滞或靠不说人话硬拖。
- **前置**：双方基于不完整但合理的证据形成不同判断。
- **骨架**：新证据强化或动摇旧判断 -> 角色据此采取有代价的行动 -> 行动产生新的可见事实 -> 误会升级或开始解开。
- **回报**：情绪拉扯、期待澄清。
- **出口**：当事人发现自己伤害了对方；幕后操作者暴露；误会解除但信任仍需修复。
- **失效**：一句正常解释即可解决却所有人拒绝开口；证据明显不可信。

### D06 共同承担后果
- **解决**：关系已经建立，但缺少深化节点。
- **前置**：一方行动产生真实代价，另一方有选择是否介入的自由。
- **骨架**：后果到账 -> 另一方可安全离开却选择分担 -> 分担方式符合其能力和边界 -> 双方关系获得不可逆的新事实。
- **回报**：信任、心疼、关系满足。
- **出口**：人情债；外界误判关系；被帮助者日后回报或抗拒依赖。
- **失效**：分担没有成本；角色只靠台词宣布情谊。

## 五、兑现与反转

### E01 错判反噬
- **解决**：需要打脸或局部爽点，但不想靠突然开挂。
- **前置**：对手已经基于可理解但错误的信息作出判断，主角底牌或能力有前文依据。
- **骨架**：对手按错判加注 -> 主角用已存在的牌做出可见行动 -> 对手的投入反成损失 -> 外部评价或局面改变。
- **回报**：爽、反差、地位变化。
- **出口**：对手调查底牌；主角暴露部分实力；旁观者改变站队。
- **失效**：对手明知真相仍强行送脸；底牌首次出现即万能。

### E02 证据闭环
- **解决**：压迫或冤屈已积累，需要实质结算。
- **前置**：前文已有两项以上可互相印证的证据或行动痕迹。
- **骨架**：主角补上关键缺口 -> 证据链在合适对象面前成立 -> 对方无法只靠否认脱身 -> 制度、关系或利益结果到账。
- **回报**：解气、逻辑满足、旧账结算。
- **出口**：幕后者切割；证据揭出更大问题；胜诉但付出关系代价。
- **失效**：关键证据临时天降；只有嘴上承认，没有后果。

### E03 前置布局回收
- **解决**：此前准备、试探或让步长期未兑现。
- **前置**：正文已经明确做过一个当时有别的表面用途的动作。
- **骨架**：旧布局在新冲突中被触发 -> 读者重新理解此前动作 -> 主角获得阶段优势 -> 对手被迫改策。
- **回报**：原来如此、智谋、连续性。
- **出口**：布局有副作用；只解决一半；对手发现主角习惯。
- **失效**：所谓前置动作此前从未出现；回收万能到解决所有问题。

### E04 小胜换大麻烦
- **解决**：需要给回报，又不能过早结束单元。
- **前置**：当前冲突可取得局部成果，但成果会触及更高利益或暴露主角。
- **骨架**：主角赢得眼前结果 -> 读者获得明确回报 -> 胜利改变利益格局 -> 更强对手、责任或风险被激活。
- **回报**：爽点与追读同时存在。
- **出口**：升级对手；承担新职位；底牌被关注。
- **失效**：每次胜利都机械招来更强敌人；新麻烦与胜利无因果。

### E05 代价延迟到账
- **解决**：此前选择太顺，缺少因果重量。
- **前置**：主角曾明确冒险、违规、透支、欺骗或牺牲某项利益。
- **骨架**：当时被暂缓的代价在最不方便时出现 -> 主角无法完全回避 -> 必须偿还或二次选择 -> 旧决定获得重量。
- **回报**：因果感、压力、人物成长。
- **出口**：补救产生新关系；失去资源；承认错误改变信任。
- **失效**：此前没有风险提示；代价只为虐主且与选择无关。

### E06 对手自食其果
- **解决**：对手需要结算，主角又不适合直接碾压。
- **前置**：对手自己建立了谎言、苛刻规则、危险计划或不公平条件。
- **骨架**：主角不正面破坏，而是迫使规则一致执行 -> 对手无法同时保住利益与说法 -> 自己承担此前施加给别人的后果。
- **回报**：解气、智取、公平反转。
- **出口**：对手迁怒；规则被集体质疑；主角获得支持。
- **失效**：规则只对反派突然生效；主角没有促成结果的行动。

## 六、转折、换挡与单元启动

### F01 结果余波启动
- **解决**：上一单元已经收束，新剧情接不上。
- **前置**：上一结果真实改变了资源、名声、关系、权力或风险，且作者允许启动下一目标。
- **骨架**：胜负结果传到受影响的人群 -> 某方据此采取新行动 -> 主角处理成功或失败的后果 -> 新目标形成。
- **回报**：连续性、世界反馈、新期待。
- **出口**：招揽、排斥、报复、责任升级或新竞争。
- **失效**：作者只想收束不想启动下一单元；上一结果没有影响任何人；新行动与结果无关。

### F07 结果确认后稳定停住
- **解决**：单元已经完成，只需用一两章让结果、人物与环境落地，不启动新任务。
- **前置**：近期核心承诺已经兑现，作者明确要收束、休息或保持当前尺度。
- **骨架**：确认胜负或任务结果 -> 受影响者作出有限反应 -> 处理一项局部欠账、损失或关系余波 -> 建立暂时新常态并停住。
- **回报**：结算完整、人物余韵、读者获得感。
- **出口**：只保留尚未到期的背景压力，不在本轮形成新目标。
- **失效**：核心结果尚未真正完成；用陌生危机破坏刚刚兑现的回报。

### F02 目标升级
- **解决**：小目标完成后缺少下一步。
- **前置**：完成旧目标后，主角获得了新的认知、能力、资格或责任。
- **骨架**：旧目标达成 -> 主角看见更高层需求或威胁 -> 新目标与旧成果直接相连 -> 必须选择是否进入更大局面。
- **回报**：成长感、地图展开。
- **出口**：新层级竞争；旧关系不再适配；能力需要新资源。
- **失效**：新目标只是数值变大；主角没有接受它的个人理由。

### F03 地图因需求打开
- **解决**：需要换场景或扩图，但怕像作者强行搬家。
- **前置**：主角已有目标在当前地点无法完成，或关键人物、资源、答案位于别处。
- **骨架**：当前环境暴露上限 -> 已有需求指向新地点 -> 主角为具体目标前往 -> 新地图首先兑现与旧地图不同的规则或利益。
- **回报**：新鲜感、扩张、目标明确。
- **出口**：进入门槛；当地利益冲突；旧问题跟随而来。
- **失效**：只为换景旅游；新地图与旧目标无关。

### F04 权限带来责任
- **解决**：主角升级或上位后只有奖励，没有新剧情。
- **前置**：主角刚获得身份、职位、能力、领地、名额或组织认可。
- **骨架**：新权限立即附带一个必须处理的责任 -> 主角第一次使用权限 -> 受益者与受损者同时出现 -> 地位变化被具体兑现。
- **回报**：升级实感、权力爽点、现实后果。
- **出口**：内部治理；旧对手受制；更高层考核。
- **失效**：责任与权限无关；升级后主角仍按原方式解决一切。

### F05 旧角色带新问题回归
- **解决**：需要重启旧线或引入变化，又不想凭空加人。
- **前置**：已有角色离场时保留了未决目标、关系或资源变化可能。
- **骨架**：旧角色因自己的目标回归 -> 带来与当前主线相交的新状态或问题 -> 主角重新评估旧关系 -> 新旧线合流。
- **回报**：熟悉感、人物回响、线索合流。
- **出口**：立场变化；旧债重提；角色成为竞争者或盟友。
- **失效**：回归只为怀旧或送消息；角色离场后毫无变化依据。

### F06 公开事件汇流
- **解决**：支线分散，角色缺少自然碰撞场合。
- **前置**：已有比赛、会议、典礼、交易、审判、任务、灾害或家族事件能合理吸引多方。
- **骨架**：各方因不同利益进入同一事件 -> 原本分离的目标发生碰撞 -> 主角选择优先处理哪条 -> 多线产生共同结果。
- **回报**：热闹、关系碰撞、阶段节点感。
- **出口**：公开站队；资源重新分配；秘密被更多人看见。
- **失效**：活动临时出现只为让所有人碰面；每个角色没有独立参会理由。

## 七、失败、低谷与恢复

### G01 有价值的失败
- **解决**：主角长期顺利，需要失败但不能原地受虐。
- **前置**：主角采取了合理但受信息、能力或代价限制的行动。
- **骨架**：主角按当前最佳判断行动 -> 对手或规则暴露其盲区 -> 主角失去一项具体东西 -> 同时获得信息、关系判断或新方法。
- **回报**：紧张、成长可信、后续反击预期。
- **出口**：修正策略；寻找新筹码；关系因失败重排。
- **失效**：失败靠突然降智；什么都没学到，只延长痛苦。

### G02 两害取轻
- **解决**：选择没有重量，主角人设难以显现。
- **前置**：两个目标确实无法兼得，且损失都与主角相关。
- **骨架**：局面压缩选择时间 -> 主角明确保什么、舍什么 -> 被舍弃的一边产生后果 -> 选择定义人物与后续矛盾。
- **回报**：人物力度、心疼、争议与期待。
- **出口**：补偿行动；被放弃者反应；主角承担长期代价。
- **失效**：作者随后轻易两全；两边价值明显不对等。

### G03 底牌失效
- **解决**：主角解决问题的手法重复，紧张感下降。
- **前置**：主角已多次依赖同一能力、身份、资源或关系。
- **骨架**：本次条件改变使常用底牌受限 -> 主角先遭遇真实挫折 -> 改用已有但少用的能力或寻求合作 -> 解决方式发生变化。
- **回报**：新鲜、成长、团队价值。
- **出口**：开发新用法；暴露依赖问题；旧底牌需要修复或升级。
- **失效**：能力限制临时编造；失效后又立刻恢复。

### G04 胜利成果被迫取舍
- **解决**：胜利后剧情归零或奖励太轻。
- **前置**：主角赢得的成果包含互相冲突的利益，或无法全部带走、保护、公开。
- **骨架**：胜利产出多个成果 -> 时间、规则或关系迫使取舍 -> 主角选择保留哪一项 -> 被舍弃部分成为后续变量。
- **回报**：胜利重量、人物选择、后续期待。
- **出口**：他人取得弃项；主角日后追索；选择暴露真实目标。
- **失效**：选择没有代价；下一章又全部拿回。

### G05 关系性低谷
- **解决**：低谷只损失战力或资源，人物情绪没有抓手。
- **前置**：主角与关键角色已有信任、依赖、承诺或共同目标。
- **骨架**：一次合理选择伤及关系 -> 双方按各自利益拉开距离 -> 主角无法只靠解释恢复 -> 必须用后续行动修复或接受变化。
- **回报**：心疼、关系期待、人物成长。
- **出口**：分线行动；第三方介入；共同危机检验是否仍会合作。
- **失效**：冲突源于刻意不沟通；关系很快无成本复原。

### G06 用旧能力解决新层级问题
- **解决**：升级只能依赖临时新技能，旧积累被浪费。
- **前置**：主角已有能力、经验或关系可以换一种组合使用。
- **骨架**：新问题表面超出主角层级 -> 主角拆出其中熟悉部分 -> 重组旧能力与现有筹码 -> 以有限方式破局而非全面碾压。
- **回报**：成长回收、聪明感、能力连续性。
- **出口**：发现旧能力升级方向；获得高层认可；新问题仍留核心难点。
- **失效**：旧能力被解释成万能；重组没有此前依据。

## 八、反应、恢复与新常态

### H01 后果先落到旁人身上
- **解决**：重大结果发生后，只写主角感受，世界没有反馈。
- **前置**：上一结果已经影响某个具体角色或群体的利益、判断或安全。
- **骨架**：结果传到受影响者 -> 对方按自身利益采取第一动作 -> 主角从对方反应看见后果 -> 决定补救、解释、利用或承受。
- **回报**：世界反馈、人物关联、因果感。
- **出口**：关系重估；名声变化；新请求或追责出现。
- **失效**：旁人只负责夸赞或震惊；其行动不影响局面。

### H02 反应本身成为阻力
- **解决**：人物刚经历重创便立刻恢复理性，心理不真实。
- **前置**：上一结果确实造成恐惧、愤怒、羞耻、悲伤、兴奋或身体失衡。
- **骨架**：人物先按本能反应 -> 反应妨碍眼前小目标或伤到关系 -> 现实迫使其调整 -> 人物在未完全恢复时作出有限决定。
- **回报**：人物真实、情绪重量、决定可信。
- **出口**：带着问题行动；接受帮助；暂时拒绝任务。
- **失效**：情绪只用于拖字数；反应与此前人物经验不符。

### H03 清点损失重排优先级
- **解决**：失败后只喊痛苦，不知道下一步处理什么。
- **前置**：人物具体失去了资源、时间、位置、关系、信息或身体状态。
- **骨架**：逐项确认损失与尚存筹码 -> 发现无法全部补回 -> 选择先保一项、暂放一项 -> 新的局部目标成立。
- **回报**：现实感、止损判断、重新起步。
- **出口**：补给、求援、修复、追责或改变原计划。
- **失效**：损失只是数字；清点后所有东西立即恢复。

### H04 暂时安全暴露真问题
- **解决**：危机刚停便急着制造更大危机，没有呼吸。
- **前置**：人物刚脱离外部危险，但身体、关系、资源或认知问题仍在。
- **骨架**：外部压力暂退 -> 人物尝试恢复正常 -> 被压住的问题在安静中显现 -> 先处理一个局部后果并决定是否继续。
- **回报**：节奏呼吸、人物层次、余波回收。
- **出口**：休整、坦白、治疗、分歧或重新出发。
- **失效**：所谓真问题临时新增；安静段没有选择与结果。

### H05 建立脆弱的新常态
- **解决**：身份、住处、队伍或关系变化后，下一章只能马上升级。
- **前置**：人物刚进入新的生活、工作、合作或受控状态。
- **骨架**：人物试着按新规则过完一次日常任务 -> 小摩擦暴露边界 -> 调整相处或做事方式 -> 新常态暂时成立并留下一个裂缝。
- **回报**：环境落地、关系熟化、长篇余量。
- **出口**：裂缝日后扩大；新规则被利用；日常职责引出事件。
- **失效**：只有设定说明；没有具体任务和状态变化。

### H06 低谷中的最小决定
- **解决**：人物无力承担大行动，却必须让故事继续。
- **前置**：人物遭受真实失败或消耗，当前只能完成有限行动。
- **骨架**：人物拒绝宏大目标 -> 确认眼下唯一还能完成的局部目标 -> 经历有效尝试、受阻与选择 -> 取得一个最小但可验证的结果 -> 由结果恢复一点主动权或暴露下一问题。
- **回报**：克制、韧性、可信恢复。
- **出口**：小承诺、小调查、小修复或等待窗口。
- **失效**：最小动作轻易解决大问题；低谷只是短暂姿态。

## 九、训练、工作与能力生长

### I01 针对缺陷的刻意练习
- **解决**：训练只写重复动作或数值上涨。
- **前置**：已有能力暴露了一个具体、可观察的缺陷。
- **骨架**：复现缺陷 -> 拆出最薄弱一环 -> 设计针对练习 -> 在新条件下验证，取得有限掌握或确认上限。
- **回报**：成长扎实、能力边界清晰。
- **出口**：形成稳定用法；需要新资源；缺陷转移到另一环。
- **失效**：练习内容与缺陷无关；一次训练便彻底消除限制。

### I02 旧技能迁移到新用途
- **解决**：已有技能只能在原场景重复使用。
- **前置**：人物已掌握某项能力，其底层原理可作用于新问题的一部分。
- **骨架**：新任务表面陌生 -> 人物认出熟悉环节 -> 调整旧技能用法 -> 解决局部问题，同时发现迁移边界。
- **回报**：聪明感、积累回收、新鲜用法。
- **出口**：形成组合技；专业价值被看见；错误迁移造成后果。
- **失效**：旧技能被解释成万能；新用途没有原理联系。

### I03 实务任务代替空练
- **解决**：成长线与剧情线互相分离。
- **前置**：已有工作、委托、照料、制作或行动需要目标技能。
- **骨架**：人物接下具体任务 -> 实际条件暴露训练中没有的问题 -> 边做边修正 -> 任务结果验证成长并留下现实后果。
- **回报**：成长与剧情合一、获得感。
- **出口**：客户或组织反馈；责任升级；发现技能新限制。
- **失效**：任务只是训练靶子；成败不影响任何人。

### I04 教别人暴露自己的盲区
- **解决**：高手或成熟角色缺少继续成长的入口。
- **前置**：人物需要指导新人、同伴或下属，双方学习方式不同。
- **骨架**：人物按自己的经验教学 -> 对方无法照搬 -> 解释过程中发现未曾意识的习惯或漏洞 -> 双方各自调整。
- **回报**：角色互动、能力理解、关系建立。
- **出口**：形成师徒边界；学生提出新用法；教学责任增加。
- **失效**：学生只负责吹捧；教学者突然领悟无关的新能力。

### I05 协作失配磨成配合
- **解决**：团队一组建便天然默契，缺少过程。
- **前置**：成员能力互补，但节奏、信息或目标优先级不同。
- **骨架**：第一次协作因具体失配受挫 -> 复盘责任与信号 -> 重分工或定规则 -> 第二次只在一个环节形成有效配合。
- **回报**：团队成长、默契爽点、人物差异。
- **出口**：固定配合；未解决的分歧；外界开始针对组合。
- **失效**：失败靠某人突然犯蠢；一次复盘便全队无缺陷。

### I06 完成交付才算成长
- **解决**：制作、经营或职业线只有过程，没有结果重量。
- **前置**：人物承担了有验收标准和真实使用者的任务。
- **骨架**：明确交付标准 -> 资源或需求中途变化 -> 人物取舍质量、时间与成本 -> 成果被实际使用并得到反馈。
- **回报**：专业感、具体成果、现实压力。
- **出口**：返工、口碑、订单、责任或技术债。
- **失效**：验收者无利益标准；成果好坏只由旁白宣布。

## 十、调查、探索与行动变化

### J01 错误假设也排除一条路
- **解决**：调查失败就完全归零。
- **前置**：人物有基于现有证据形成的可验证假设。
- **骨架**：按假设取证 -> 关键结果不支持原判断 -> 排除一个对象或方法 -> 错误本身指向新的具体问题。
- **回报**：推理参与、失败有价值、方向收紧。
- **出口**：改查动机、时间、渠道或证人。
- **失效**：假设毫无依据；失败后答案靠新角色直接告知。

### J02 证人先谈自己的需求
- **解决**：知情人像信息柜台，问什么答什么。
- **前置**：证人掌握独家信息，也有安全、利益、名誉或关系需求。
- **骨架**：人物求证 -> 证人回避或提出自己的问题 -> 双方交换有限行动 -> 信息只交付到其利益允许的程度。
- **回报**：人物真实、信息有价、关系博弈。
- **出口**：继续履约；证词有保留；证人成为合作者或风险。
- **失效**：证人要求与其处境无关；条件只为拖延答案。

### J03 调查动作惊动目标
- **解决**：主角长期查探，对方世界毫无反应。
- **前置**：调查需要接触记录、人物、地点或资源，必然留下可被发现的痕迹。
- **骨架**：主角取得一项进展 -> 目标方察觉异常但未必知道是谁 -> 对方调整、清理或放出误导 -> 调查变成双方互动。
- **回报**：紧张、对手能动性、智斗预期。
- **出口**：抢救证据；反向追踪；假装中止调查。
- **失效**：对方全知；调查痕迹此前根本不存在。

### J04 线索在使用中显出意义
- **解决**：物件、记录或规则只能靠解释揭谜。
- **前置**：已有线索具备实际功能、来源或使用场景。
- **骨架**：人物为现实任务使用线索相关之物 -> 反常效果或限制出现 -> 旧痕迹获得新解释 -> 立即影响当前做法。
- **回报**：自然揭示、前后呼应、世界落地。
- **出口**：验证来源；复制用途；发现曾有人用过。
- **失效**：使用场景为揭谜硬造；效果与旧线索无关。

### J05 到达目的地却找错了问题
- **解决**：探索或寻人到点后只能直接拿答案。
- **前置**：人物根据合理线索抵达地点或找到对象，但认知仍不完整。
- **骨架**：人物按预期寻找目标 -> 现场事实推翻问题设定 -> 原来要找的不是人、物或原因 -> 目标缩小、改写或暂时中止。
- **回报**：探索变化、认知反转、新问题具体。
- **出口**：追真正目标；先处理现场后果；重新解释路线。
- **失效**：前面线索全是假；转折只为延长路程。

### J06 行动成功却留下可追踪痕迹
- **解决**：潜入、偷取、营救或试探成功后没有后果。
- **前置**：行动使用的能力、身份、工具或路线会留下符合规则的痕迹。
- **骨架**：人物完成局部目标 -> 清理时发现无法抹掉的一处痕迹 -> 选择伪装来源、抢时间或接受暴露 -> 下一压力由自己的成功产生。
- **回报**：成功有重量、追读、规则感。
- **出口**：误导追查；知情者交易；身份风险上升。
- **失效**：痕迹临时出现；对方凭痕迹直接全知全能。

## 十一、日常、关系与人物停留

### K01 共同劳动代替强行谈心
- **解决**：关系推进只能靠坐下互诉心声。
- **前置**：双方有一项必须共同完成的照料、整理、制作、值守或生活任务。
- **骨架**：分工体现习惯与边界 -> 小失误或沉默暴露状态 -> 一方用行动调整 -> 任务完成使关系产生一项可见变化。
- **回报**：自然互动、生活感、默契或隔阂。
- **出口**：形成习惯；交换小秘密；未说出口的问题保留。
- **失效**：劳动只是背景；关系变化仍只靠解释台词。

### K02 照料被拒后尊重边界
- **解决**：受伤或脆弱角色一被关心就立刻软化。
- **前置**：一方确实需要帮助，却因尊严、恐惧、戒心或习惯拒绝。
- **骨架**：帮助者直接介入遭拒 -> 改为提供选择或退到安全距离 -> 对方主动接受一小部分 -> 信任只前进一步。
- **回报**：克制温情、人物自主、关系可信。
- **出口**：以后主动求助；边界被旁人误解；照料者承担等待。
- **失效**：拒绝只为撒娇；帮助者用强迫被证明完全正确。

### K03 小事检验关系边界
- **解决**：关系已有定义，却没有生活中的真实表现。
- **前置**：双方已形成合作、亲密、上下级或敌对关系，但边界仍未稳定。
- **骨架**：一件低风险小事要求借用、代劳、保密或让步 -> 双方反应暴露默认边界 -> 协商或冲突 -> 新规则落地。
- **回报**：人物细节、关系进展、轻冲突。
- **出口**：小规则日后遇到大考验；一方发现彼此理解不同。
- **失效**：小事与关系无关；结果被后文无视。

### K04 庆祝暴露分配不均
- **解决**：胜利后只有集体欢呼，余波单薄。
- **前置**：成果由多人付出，功劳、奖励、关注或损失并不平均。
- **骨架**：群体庆祝并分配成果 -> 被忽略者或获利者作出反应 -> 主角必须承认、补偿、拒领或接受 -> 团队位置改变。
- **回报**：胜利重量、群像、现实关系。
- **出口**：人情债；隐性竞争；真正贡献被看见。
- **失效**：不满者只因嫉妒；分配没有任何后续影响。

### K05 缺席者改变场内关系
- **解决**：重要角色离场后像从未存在，群像停滞。
- **前置**：该角色平时承担了明确功能、情绪位置或权力平衡。
- **骨架**：角色缺席 -> 原由其承担的任务或调和无人接手 -> 留下的人重新分工与评价 -> 缺席者的价值或问题被重新认识。
- **回报**：人物回响、群像生长、关系重排。
- **出口**：寻找、等待、替代者上位、回归时产生变化。
- **失效**：缺席没有影响；所有人只轮流回忆赞美。

### K06 玩笑或消遣露出真需求
- **解决**：轻松场景只有插科打诨，不能留下内容。
- **前置**：人物在游戏、闲聊、逛街、吃饭或休息中降低防备。
- **骨架**：低风险互动建立轻松规则 -> 一个选择或玩笑碰到真实在意之处 -> 人物遮掩、追问或改变态度 -> 留下小信息或关系变化。
- **回报**：节奏呼吸、人物魅力、含蓄推进。
- **出口**：日后回收真话；小赌注变成承诺；关系出现新称呼或习惯。
- **失效**：靠冒犯制造尴尬；轻松段结束后一切无痕。

## 十二、群体、制度与秩序

### L01 分配方案逼出真实优先级
- **解决**：资源稀缺只写争吵，没有人物选择。
- **前置**：资源确实不足，存在多个合理需求与可执行分配权。
- **骨架**：各方提出分配理由 -> 规则无法同时满足 -> 决策者确定标准并承担得罪谁 -> 结果改变群体关系与责任。
- **回报**：治理感、价值观、群像张力。
- **出口**：被舍弃者另寻渠道；标准被复制或挑战；资源来源成为目标。
- **失效**：某方需求明显不合理；主角临时变出足够资源。

### L02 谣言沿利益链变形
- **解决**：名声与舆论只由作者一句话改变。
- **前置**：已有事件被不同群体看见，各方关注点与利益不同。
- **骨架**：事实传给第一批人 -> 每一层按自身利益删改重点 -> 变形信息影响具体行动 -> 主角决定澄清、利用或保持沉默。
- **回报**：世界活性、名声反馈、信息战。
- **出口**：错误期待；群体站队；真相公开时反噬。
- **失效**：谣言无传播渠道；所有人恰好相信同一版本。

### L03 交接遗漏形成责任空档
- **解决**：组织流程只有背景说明，无法生成剧情。
- **前置**：任务、岗位、病人、物资或情报需要在角色或部门间交接。
- **骨架**：旧负责人保留、遗漏或误解一项信息 -> 新负责人按不完整记录行动 -> 问题出现 -> 双方必须查清责任并补流程。
- **回报**：制度真实、调查、职业冲突。
- **出口**：发现故意隐瞒；建立新流程；替人背责或拒绝背责。
- **失效**：遗漏纯属常识性粗心；组织没有任何记录机制。

### L04 群体对风险承受度分裂
- **解决**：团队或社区面对危机时意见过于一致。
- **前置**：不同成员拥有不同可失去之物、信息和退出条件。
- **骨架**：同一风险逼近 -> 保守与冒险方案各有受益者 -> 群体必须投票、分线或交权 -> 结果形成新的领导与裂缝。
- **回报**：群像、领导力、真实选择。
- **出口**：分队行动；少数派自救；失败后责任追究。
- **失效**：一方方案明显愚蠢；分裂靠煽动者无理由挑事。

### L05 功劳归属改变权力
- **解决**：完成大事后地位变化只靠口头表扬。
- **前置**：多人参与成果，组织会据记录、公开叙事或利益分配认定功劳。
- **骨架**：成果上报 -> 不同角色争取、让出或隐瞒贡献 -> 归属落定 -> 权限、责任、敌意或人情随之变化。
- **回报**：地位实感、职场或势力博弈。
- **出口**：被抢功者取证；主角主动藏功；获功者承担新任务。
- **失效**：功劳认定没有任何利益；所有人都无条件谦让。

### L06 局部修补触发系统自保
- **解决**：主角找到规则漏洞后可以无限利用。
- **前置**：制度或组织已从漏洞中遭受可感知损失，并具备修正规则的能力。
- **骨架**：主角用漏洞取得一次成果 -> 管理方复盘损失 -> 补丁关闭旧路并影响无辜者 -> 主角决定另找方法、公开争取或承担连带后果。
- **回报**：世界反应、规则博弈、胜利代价。
- **出口**：新漏洞；群体不满；制度内部出现不同意见。
- **失效**：系统为针对主角全知更新；漏洞此前并未造成损失。

## 组合规则

可优先考虑以下功能组合，但仍须通过事实、人物利益和推进预算校验：

- 主角失去目标：优先 `A01-A06/H03/H06`；只建立一个近期小目标。
- 连续蓄势待兑现：优先 `E01-E03/E06`；需要保留压力时按需接 `E04/E05`。
- 单元刚收束且只想停住：优先 `F07/H01/H04/H05`；只有作者明确允许启动下一单元时，才考虑 `F01-F04`。
- 关系停滞：优先 `D01-D06/K01-K06`；关系边界、信任或相处方式出现可见变化即可，不强制改变外部局面。
- 训练或工作空转：优先 `I01-I06`，让成果接受实际任务或使用者检验。
- 调查线索拥堵：优先 `C01/C02/J01/J02`，每次验证至少排除一个选项或改写一个判断。
- 主角长期顺风：优先 `G01-G05/J06/L06`；代价必须来自既有规则，失败也应产生可用结果。
- 近期套路同质：更换场景原型、行动发起者、阻力来源或结果类型，不能只换人物和地点。
