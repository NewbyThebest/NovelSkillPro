## 按授权风险预筛

以下编号不是永远禁用，而是含有容易越过保守预算的典型出口。作者未授权对应变化时，不进入初选：

| 需要明确授权的变化 | 高风险套路 | 未授权时的替代方向 |
| :--- | :--- | :--- |
| 启动下一目标或新单元 | F01、F02、F05、F06 | F07、H01、H04、H05 |
| 正式进入新地图 | F03 | P21 对应的途中闭环、H05、J04 |
| 正式身份、权限或地位跃迁 | F04、E01 | 临时职责、一次评价、局部资源结果 |
| 新增长期敌对线或扩大冲突层级 | B03、B05、E04、F05、F06 | 既有角色的一次利益反应、E05、H01 |
| 关系正式定性 | D01、D06、G05 的不可逆出口 | K01—K03、K06、有限 D03—D05 |
| 核心秘密曝光或真相闭环 | C02、C06、E02 的高幅度出口 | A04、C01、C03—C05、J01—J04 |

同一套路可能有低幅度和高幅度出口。只有完整骨架、结果与出口都在预算内才可保留，不能只凭编号放行。

## 组合纪律

- 默认一个主套路足够；只有主套路缺一个关键环节时加入一个辅套路。
- 主套路负责“为什么发生以及发生什么变化”，场景原型负责“在哪里、通过什么行动发生”，变化机制负责“怎样变难或改向”，结果类型负责“到哪里停”。
- 路线毛坯之间至少更换两项：场景原型、行动发起者、主要阻力、转折机制或结果类型；正式候选还须在核心策略、逐章功能或结果、最终停点中形成实际差异。
- 不能把同一个套路换人物名后当成多条候选。
- 题材转换最后执行，只改变载体和回报表达，不改变人物因果。
