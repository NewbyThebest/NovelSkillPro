# 正文审查规范 · 共用

本文件与三份分册规范配套使用。分册规定读什么材料、核什么；本文件规定所有分册共同遵守的事项。

## 审查方只读

审查全程只读：不改写正文、设定、大纲或控制台，不代替作者决定剧情。发现的问题由写作会话处置。

- 将校准脚本目录记为 `SCRIPTS_DIR`（即 `.agents/skills/webnovel-zhengwen/scripts/`），包含 `.agents/` 的项目根目录记为 `WORKSPACE_ROOT`。
- 审查对象只有一处：待审正文草稿 `4-正文/第X章_草稿_[标题].md`。分册指定的材料均围绕这一处核对，不审查其他章节、不审查全局资料。

**下列材料任何分册都不读取**：

- `控制台/伏笔追踪.md`、`控制台/进度.md`
- `2-设定/2.3.2_核心关系.md`
- `2-设定/2.4_文风.md`
- `3-大纲/3.1_全书结构总纲.md`、`1-预期/`
- 其他章节的章纲条目与其他章节正文
- 其他分册的规范文件与材料

材料缺失时只指出无法判断的项目，不把缺失材料当作问题本身。

**分册的某一步判断为本章没有对应内容而不读材料时**，该步在报告中不列出、不写“不适用”、不解释原因，直接做下一步。

## 处置分级

审查方必须把每一项发现明确归入下列两类之一，**不得含混**。只报本册步骤范围内的发现，不属于本册的即使看到了也不写进报告。

### 一、问题（必须修复）

对照本分册步骤的核对对象，可以直接判定的不符合项。本册报哪几类写在本册步骤中。

- **硬性不符合**：产出格式、脚本校准未执行、创作原料遗漏、正文与项目根 `AGENTS.md` 的规则冲突。
- **事实矛盾**：与时间线、地图、角色状态、能力资源总账或已确认设定冲突，或结果无法由人物行动、已知规则、前置线索推出。
- **读者无法理解**：信息缺失或表述导致读者读完该处后无法确定发生了什么。

每条问题必须写明：**位置**（正文的段落或原文引用，以及对照的那份依据文件与其条目）、**依据**（不符合哪条）、**为什么是问题**、**修改方向**。只写"这里不好"不算问题。

### 二、建议（只提出，不要求修改）

审查方认为可以更好、但依据中没有强制要求，或不构成确定的错误的意见。各分册的建议类别写在本册步骤中。

**「本章待确认」与「设定待补全」不属于建议，不写进报告。** 草稿尚未定稿，正文新落地的地点、角色、资源与设定细节还没有回写控制台和设定，是正常状态，回写由定稿流程负责。

建议只要求写清**位置**与**想法**，并明确它是建议。**不得把建议写成问题，也不得用问题的方式要求修改**。

### 判定不确定时

无法在合理成本内定论时，如实写"未验证"并说明还缺什么材料，不硬下结论，也不凭"应当没问题"放行。**判不出属于问题还是建议时，一律归入建议**，在报告中说明存疑之处；不要在两节之间来回权衡。

## 效率约束

审查服务于交付，不做无边界挑刺：

1. **一步一读一核**：按分册的步骤顺序执行，每步读该步指定的材料、核该步写明的内容，核完即做下一步。不要先通读全部材料再回头核对，也不要边读边判断"还需要什么材料"。
2. **走完步骤即完成**：审查以分册的步骤逐条走完为准。走完即视为审查完成，不必另行设想"可能存在的问题"再逐一排查——规范要求的是发现不符合项，不是穷举所有可能的不符合项。各步有依据的疑点按「处置分级」处理；走完没有疑点就结束，直接出报告。
3. **一次取证**：在同一轮审查内，同一命令只跑一次；判断到可以落笔的程度即停止追查。
4. **可以无发现**：全部通过时直接输出通过结论，不为了显得尽责而凑问题或把建议包装成问题。
5. **只审本章**：发现的问题若属于其他章节或全局资料，只记录并说明交由对应流程处理，不在本章强求。
6. **只审本分册**：非本分册负责的内容一律不判断，也不在报告中出现。

## 执行流程

审查**一轮完成，不做复审**：报告交付后本次审查即结束，写作会话修正后不再发回审查方。修正是否引入新问题，由写作会话的脚本校准与自检卡负责。

1. 说明审查范围与已读材料。
2. 按分册的步骤顺序执行。判断必须落到具体文件、章节、段落或事实。
3. 按「处置分级」把发现分入问题与建议两类，逐条写清位置、依据与理由。
4. 输出报告，交付给写作会话处置。报告交出后本次审查结束。

## 报告结构

```markdown
# 《[作品名或文件名]》正文审查报告 · [分册名]

审查范围：[材料]
已读材料：[文件]

## 验收结论
[通过 / 有问题待修复 / 无法判定；未通过时列出阻断项]

## 已核对范围
[列出本分册实际核对的内容与主要材料]

## 问题（必须修复）
- **位置**：
  **依据**：
  **为什么是问题**：
  **修改方向**：
[无问题时写"未发现问题"]

## 建议（仅供参考，不要求修改）
- **位置**：
  **想法**：
[无建议时写"无"]

## 无法判定
[缺材料的项目；无则写"无"]
```

**各节无内容时按上面括号里的说明处理**，不要在报告里解释为什么某一节是空的。

审查项没有证据时明确标注，不为凑报告补造问题。
