# 文风文档

**使用时机：小说立项阶段，一次性完成。**

产出 `2-设定/2.4_文风.md`，并把参照作品的语料复制进 `2-设定/参考作品/`。

## 文档要装什么

两块：

| 块 | 内容 |
| :--- | :--- |
| **一、语料来源** | 写作时查哪两路、怎么取、冲突时以谁为准 |
| **二、本书的文风要求** | 本书要求（优先级最高） |

## 第一步：确定参照作品

问用户：**这本书摹仿谁？还是不摹仿任何作品？**

- **摹仿某部作品**：取得作品名、作者、语料路径。
- **不摹仿**：跳过本步，文档里不写参照作品。

### 语料形态

两种：

| 形态 | 例子 | 怎么读 |
| :--- | :--- | :--- |
| **单文件** | 一本小说的 txt | 文内按「第N章」分章，自己定位后读 |
| **目录** | 某个项目的 `4-正文/` | 一章一个 md 文件，文件名含「第N章」 |

「第N章」的 N **有阿拉伯数字也有中文数字，两种都要认**。

**自己定位要读的章**：单文件先用 `grep -nE "^第[0-9一二三四五六七八九十百]+[章回]"` 拿到全部章节的行号，再按行读完整章；目录直接读文件。整章读，不要截段。

**目录形态只读定稿**，草稿、备份不是这本书已发出的声音。

### 语料必须先复制进项目

**参照作品不能只留一个外部路径。** 外部语料随时可能被移走或删除，文档就会失去依据，写作阶段再想读也读不到。取得语料后，**先把语料复制进 `2-设定/参考作品/`**，再开始读；文档里写的语料路径是这份项目内副本，不是外部原件。

- **复制，不要移动**：外部原件可能还有别的用途，移动它等于替别人做决定。
- **单文件**：整个 txt 复制过来，保留原文件名，例如 `2-设定/参考作品/少年歌行.txt`。
- **目录**：整个目录复制过来，例如 `2-设定/参考作品/〈作品名〉/`，保留原有的章节文件命名，不改名、不合并、不挑选。
- **复制完先验证**：单文件比章节数，目录比文件数，并实际读出一章原文确认能读出来。数目对不上或读不出来，说明复制不全，必须重做——复制不全等于没有备份。
- **已经在本书项目里的语料不必再复制**：它本来就不怕外部删除，路径直接指向它。

### 该读哪几章，自己判断

**没有脚本替你挑章。** 判断哪些章对口，要靠读——**看标题、看内容**，不是数词。

- **标题有信息量的按标题挑**（「第177章 断风一枪」像打斗）
- **标题看不出的，抽几章读读**，读完就知道这本书有哪些场面
- **找到对口的场面后，再找同类章**（同类章往往标题用词也相近）

**不要用一套通用的场面分类套所有书。** 这本书写什么题材，就找什么场面的章。

## 第二步：问作者本书要求

**先问清这个，再去读参照作品。** 问作者：**这本书有什么额外要求？** 他不说，没人知道。

例：

- "叙述用词偏古，现代事物用当代语言直述"
- "对白符合人物年龄身份，保持个人口吻"
- "场面再重也不写成阴郁"
- "金手指只演示不解释，不出面板、不出提示音"

这类要求直接记下，**这是作者的决定，不需要论证**。

**本书要求优先级最高。** 写作阶段本书要求与参照作品冲突时，**以本书要求为准**——这条要写进文档，让写作者知道。

## 第三步：读参照作品，判断它是什么样的文风

**这一步只做一次，所以尽量多读。** 读 **30 个章节**的完整原文，覆盖多种场面。参照 `references/提取框架.md`——那一页列的是**跨作品通用**的判断角度，换哪本书都用这一套。

**读不出来就跳过，不要硬套。**

### 结论留在脑子里

读原文是为了判断**这本书的文风是什么样的**。**结论不写进文档**——写作时去读原文就有，写成条目反而会让写作者照着条目凑。它放汇报里，凭它和作者确认参照作品选得对不对。

## 产出格式

按 `assets/文风文档模板.md` 写。**模板里的章节、条目、字段就是最终文档的全部内容**——只填它，不新增小节、不加它没有的字段。想到的补充内容放汇报里。

**过程文件不要留在项目里**：抽出的原文、中间稿、统计脚本一律放临时目录，写完文档后删掉。**项目里只留两样**：`2-设定/2.4_文风.md`，以及 `2-设定/参考作品/` 下的语料副本——语料副本是长期依据，不是过程文件，不得清理。

## 校验

写完后逐条过：

- [ ] 「语料来源」是否写明写作阶段**同时查两路**（本书 `4-正文/` ＋ 参照作品）？
- [ ] 是否写明**本书优先**，且冲突时以本书为准？
- [ ] 参照作品是否写清了作品名、语料路径、取用方法？
- [ ] **语料是否已复制进 `2-设定/参考作品/`**，且文档里的路径指向这份项目内副本？
- [ ] **版本核对通过**：单文件比章节数、目录比文件数，且实际读得出一章原文？
- [ ] 取用方法是否说明了"读完整原文、10 个章节、挑对口的场面"？
- [ ] 本书那一路是否写明"只读定稿"？
- [ ] 「本书要求」是否都问过作者？
- [ ] **文档里有没有写法条目、教程、范例这类东西？→ 全部删掉**（写法由写作者读原文自己判断）
- [ ] **文档里有没有模板之外的条目、小节或字段？→ 删掉**
- [ ] **临时文件是否已清理？**
