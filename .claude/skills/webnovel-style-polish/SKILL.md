# 文风润色

把已有正文改到 `2-设定/2.4_文风.md` 要求的样子。

由正文写作流程按用户选择调用，也可对任一已有正文单独执行。

## 承载方式

**必须由独立子代理承载，不在写作会话内自行润色。**

- **由写作会话或用户直接调用时**：在写作会话之外拉起独立子代理，把本技能文件、待润色正文、`2-设定/2.4_文风.md`、本章章纲条目位置、本章出场角色档案路径交给它，由它读取本技能文件并执行。**任务书只给这些路径**，不写剧情摘要、改法提示或任何结论性说明；读什么、怎么改由本技能规定。夹带了就把任务书改干净重发。
- **已在独立子代理中运行时**：直接执行，不再向外拉起子代理，不嵌套。

宿主不支持拉起子代理时，告知用户本技能不可执行并停止，不得跳过隔离直接润色。

## 读取范围

只读这六类，**此外任何文件都不读**：

- 本技能文件
- `2-设定/2.4_文风.md`
- 该文件「语料来源」一节指明要读的语料
- **本章章纲条目**
- **本章出场角色的档案**：`2-设定/` 下的 `2.3_主要角色设定表.md`、`2.3.1_阶段与功能角色记录.md`，以及角色归档中对应角色的条目
- 待润色的那一份正文

除此以外不读任何文件，也不在项目里检索。

## 边界

**不能脱离本章章纲。**

## 执行

**第 1 步备料，第 2 步参照作品的文风，第 3 步核对文风文档「本书要求」，第 4 步校准，第 5 步交付。**

按顺序执行，**一步一落地**：做完当前步、把改动写进文件，再进下一步；不得把判读与改法只留在思考里。

**不想后面的步骤。** 做这一步时不想后面任何一步，也不盘算各步如何分工——轮到哪一步，再想哪一步。

**每步独立，大胆改。** 每一步只管把自己这一项改到位，不必顾虑和别的步骤冲突——按顺序改下去，后面的步骤会覆盖前面的。先把改动落实，有冲突后面自会修正。

**不管字数。** 不要因为怕字数变化就不改，该加就加、该删就删；改到位优先于控制篇幅。

## 第 1 步 · 备料

读齐本次润色需要的材料。三类都要读到，次序不限：

- **待润色的正文**。完整读，先只读。
- **本章章纲条目**。长篇取当前十章章纲文件中的对应条目，短篇取 `3-大纲/短篇章纲.md` 中的对应条目。看清本章的剧情骨架、人物选择、结果、伏笔与结尾状态。
- **文风文档** `2-设定/2.4_文风.md`。它是本次润色的唯一依据，完整读。

同时记下**改动前的字数**，后面交付要报变化（`<正文技能目录>` 为 `.agents/skills/webnovel-zhengwen/` 的实际绝对路径）：

```bash
python "<正文技能目录>/scripts/count_chinese_words.py" <章号> "4-正文"
```

读完即进入第 2 步。

## 第 2 步 · 参照作品的文风

**先取语料**：按文风文档「语料来源」一节写明的取法取料，读几章、怎么挑以那份文件为准。它列的两路都查。

**再按下述做法过一遍正文**：

1. 重新完整读一遍正文。
2. 以**段落**为单位逐段判：这一段放回参照作品里，像不像？
   照着语料判，不要照着几条名目判——语料里有的，这里都算；哪一处不像，就改到像为止。
3. 判完按三种处置改：
   - **合要求的**：原样保留，一个字不动。
   - **不合要求的**：**改写这一段本身**，改到像为止。
   - **参照作品的文风而整章缺席的**：补写。
4. **除不能脱离章纲这一条外，一律放开手脚改。** 该补的补足，该重写的重写；不要因为"原文也能读"就手下留情。

本步做完即进入第 3 步。

## 第 3 步 · 核对「本书要求」

读文风文档「本书要求」，一次判齐所有条目。条数与内容以文档为准，本技能不预设、也不点名。

1. 逐条读「本书要求」的原文，明确每一条要的是什么。
2. 重新完整读一遍正文。
3. 以**段落**为单位逐段判：这一段合不合这些要求？段落内部的问题（措辞、句式、视角落点）与段落本身的问题（长短、节奏、该分该合、插话落在哪）一并判。
4. 判完按三种处置改：
   - **合要求的**：原样保留，一个字不动。
   - **不合要求的**：**改写这一段本身**——换句式、换措辞、调断句、并段或拆段、调视角落点。
   - **要求而整章缺席的**：补写，按文风文档的要求补上。
5. **除不能脱离章纲这一条外，一律放开手脚改。** 该补的补足，该重写的重写；不要因为"原文也能读"就手下留情。文风文档要求到什么程度，就改到什么程度。

改动写进文件后即进入第 4 步。

## 第 4 步 · 脚本校准（强制）

**校准脚本只在本步执行。** 前面各步不运行、不试运行、不读脚本文件。（字数统计脚本不受此限，它只在第 1 步与第 5 步运行。）

这是**最后的排版要求，与文风无关**。脚本管的是标点、引号与断行的物理格式；文风管的是句子、段落与用词。前面各步按文风文档改出来的结果，不因脚本调整了排版就算不符合文风，也不必为了迁就排版回头重改文风。

各步改写后重跑一遍正文技能的脚本校准（`<正文技能目录>` 为 `.agents/skills/webnovel-zhengwen/` 的实际绝对路径）：

```bash
python "<正文技能目录>/scripts/check_sentence_linebreaks.py" --fix "<正文路径>"
python "<正文技能目录>/scripts/fix_quotes.py" --fix "<正文路径>"
```

校准完即进入第 5 步。

## 第 5 步 · 交付

告知润色后的正文路径、字数变化，以及脚本校准的汇总行。发现与文风无关的问题一并说出来，交回写作会话处理。

字数变化用同一脚本再跑一次，与第 1 步记下的数字相减：

```bash
python "<正文技能目录>/scripts/count_chinese_words.py" <章号> "4-正文"
```

## 写入范围

只写待润色的那一份正文文件，不写其他任何文件，不新建文件。
