# 同步智能体

`.agents/skills/` 是唯一源头，`.claude/skills/` 和 `.codebuddy/skills/` 是镜像。所有技能修改只改 `.agents/skills/`，不要直接改镜像目录，否则下次同步会覆盖。

项目文本规则统一维护在仓库根目录的 `AGENTS.md`，不再使用或同步任何 `rules/` 目录。

本技能只同步技能目录；`.DS_Store`、`__pycache__/`、`*.pyc` 等本机缓存不属于镜像范围，也不会被同步过去。

## 执行流程

1. 切到项目根目录（能看到 `.agents/` 和 `.git/`）。
2. 先执行预览，不写入：

   ```bash
   python .agents/skills/sync-agent/scripts/sync.py
   ```

3. 根据预览汇总说明会新增、更新和删除哪些镜像文件与目录。预览无改动即结束。
4. 只有用户明确要求同步或确认预览结果后，才执行：

   ```bash
   python .agents/skills/sync-agent/scripts/sync.py --apply
   ```

5. 应用后再次执行预览；仅当显示“无改动，已一致”才报告同步完成。

## 同步规则

- 同步范围：`.agents/skills/` → `.claude/skills/`、`.codebuddy/skills/`。
- 真镜像：源头新增→`[新增]`，改动→`[更新]`，源头已删→`[删除]`。

### 删除语义

在源头删掉整个技能目录后，同步会**整体删除**镜像里对应的技能目录，包括目录内残留的缓存文件，不留空壳。同样地：

- 镜像里源头没有的顶层技能目录 → 整体删除。
- 现存技能里源头没有的子目录 → 整体删除。
- 镜像里源头没有的单个文件 → 删除。
- 预览模式同样报告这些删除，不会出现“预览说一致、实际还有残留”。

删除是 `--apply` 才会真正执行；预览永远不写入。

### 安全阀

源头 `skills/` 目录缺失，或存在但没有任何技能目录时，脚本会跳过该次同步并打印 `[跳过]`，不执行任何删除，避免源头异常（如未同步的仓库、误清空）导致镜像被清空。

### 同步范围之外

不为镜像目录保留专属技能文件。确有共享之外的本机配置时，放在同步范围之外。
`.claude/skills/` 或 `.codebuddy/skills/` 下如果需要放不属于镜像的文件，它会被下一次同步当作“源头已无”删掉。
