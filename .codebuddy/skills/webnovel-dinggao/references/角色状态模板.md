# 角色状态追踪

## 使用规则

本文件是下一章直接读取的动态状态工作表，不是已登场角色名册或逐章历史。

**收录范围**：只追踪 `2-设定/2.3_主要角色设定表.md` 中已经建档的主要角色。阶段与功能角色、未揭身份的路人、只承担场景作用的角色，以及尚未建档的人物，一律不写入本文件；需要在正文里追踪其状态时，先将其建档进 `2.3`，或改用 `2-设定/2.3.1_阶段与功能角色记录.md` 记录。

在上述范围内，只保留当前场景、下一章承接或当前阶段目标与约束仍需直接读取的角色。各字段覆盖更新，不按章节追加经过。

**只写变化中的状态**：稳定身份、年龄外貌、境界、等级、职衔、随身护具这类不会变的档案写入 `2.3_主要角色设定表.md`，本文件不复制。同一件事只在一个字段里说一次：对手、期限、承诺写在“当前目标与压力”，不再在“关键关系状态”里重讲一遍。不写对人物的解读与推断（如“这说明他并不接受某套说法”），只写他做了什么、说了什么。

“最近更新依据”只记录最后一次实际改变角色状态的定稿章节。主角完整能力、资源、关键物品、凭证和证据写入 `控制台/主角能力与资源.md`；长期未决问题写入伏笔追踪；逐章过程写入定稿正文和十章章纲。

角色死亡、永久离场、完成场景作用，或其状态已不影响当前阶段创作时，删除对应条目；重新进入当前规划时再补回。
