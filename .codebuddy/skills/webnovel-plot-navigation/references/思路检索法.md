# 思路检索法

卡文时先定位故事链缺了哪一环，再检索场景与套路。不能先看见一个大目标，便直接把它搬到最近几章。

## 一、确定当前叙事状态

将当前章节归入最接近的一类：

| 状态 | 识别信号 | 下一步通常缺什么 |
|---|---|---|
| 行动将启 | 人物已有明确目标，尚未执行 | 进入目标的具体场景与第一道阻力 |
| 行动进行 | 人物正在争取目标 | 阻力升级、策略改变或结果 |
| 结果刚落 | 上一行动刚成功或失败 | 后果、反应与新判断 |
| 选择悬置 | 人物面对多个有代价的选项 | 决定及其行动化 |
| 目标完成 | 近期问题已解决 | 余波、休整或新目标来源 |
| 目标断失 | 人物只能等待事件 | 欲望、责任、损失或机会转成小目标 |
| 信息拥堵 | 线索很多，不知先动哪条 | 一个可验证问题与取得答案的场景 |
| 情绪欠账 | 大事发生后人物尚未消化 | 反应、关系处理与决定 |
| 节奏重复 | 连续使用相似冲突和结果 | 更换场景功能、阻力来源或结果极性 |

若一章包含多个状态，从最近一次明确结果开始，选择其后最早尚未场景化、且不处理便无法继续的一项作为主状态。

## 二、变化刻度

同样叫“推进”，幅度可能完全不同。按轴判断本轮允许到哪一级：

| 变化轴 | 局部变化 | 大变化 |
| :--- | :--- | :--- |
| 任务 | 完成一次尝试、验证、交付或救急 | 完成整个阶段任务或更换主目标 |
| 信息 | 验证一个假设、排除一个选项、改写一段解释 | 揭开核心真相、锁定最终敌人或解开主要谜底 |
| 资源与处境 | 得失一次性资源、改善一个具体条件 | 建立稳定渠道、彻底脱困或改变生存层级 |
| 情绪 | 承认、压下或处理一种当前反应 | 完成创伤治愈、彻底放下长期执念 |
| 关系 | 信任、戒心、边界、依赖、称呼或分工中的一项移动一级 | 告白、决裂、结盟、归属或敌友关系正式定性 |
| 能力 | 提高已有动作或效果的稳定性、精度、时机或消耗控制；确认限制 | 新增此前做不到的效果、组合成独立新招、突破境界、消除核心限制或战力跨层 |
| 身份地位 | 一次评价、临时职责或局部名声变化 | 晋升、转籍、公开身份、获得正式权限或阶层跃迁 |
| 空间地图 | 途中地点、短暂停留、局部环境认知 | 抵达被作者冻结的目的地，或正式进入新地图并启动其主要人物与矛盾 |
| 主线阶段 | 保持背景压力或轻微痕迹 | 收束阶段、切换阶段、进入终局倒计时 |

作者说“前进一步”时，默认只允许对应轴的一项局部变化。作者说“不升级”时，默认禁止能力、身份、空间和阶段的大变化，不禁止熟练、信息、情绪、关系边界或局部任务结果。

## 三、定位缺环

使用完整因果环诊断：

`上一结果 → 反应 → 困境 → 决定 → 场景目标 → 阻力 → 转折 → 选择／行动 → 结果 → 新状态`

这条链只用于定位故事当前停在哪里，不是单章结构模板。缺环决定下一章从何处承接，但整章仍须围绕一个主功能形成足量展开；反应、休整和关系章不必硬造大转折，也要通过多轮有效互动、受阻、选择或状态变化支撑完整篇幅。行动章可以不写完长期任务，却必须取得本章可见结果。

按缺口检索：

| 缺环 | 常见症状 | 优先问题 |
|---|---|---|
| 上一结果 | 下一章像另起炉灶 | 上一章究竟改变了什么？谁最先受影响？ |
| 反应 | 人物刚受重创便立刻理性行动 | 他第一反应是什么？这会妨碍什么？ |
| 困境 | 人物随便选都没有代价 | 哪两项不能兼得？不选会失去什么？ |
| 决定 | 人物想很多却不动 | 他愿意承担哪种代价？决定怎样变成动作？ |
| 目标 | 章节只有闲聊、走路或观察 | 本场结束前，人物具体想得到什么？ |
| 阻力 | 目标轻易完成 | 谁的利益、规则、能力、环境或内心在阻止？ |
| 转折 | 冲突只是重复加码 | 什么新信息或行动会让原办法失效？ |
| 行动 | 主角被剧情拖着走 | 他能试探、交换、隐瞒、争取、拒绝或承担什么？ |
| 结果 | 写完一切照旧 | 哪一项局部价值从开头状态变到结尾状态？ |
| 新状态 | 章尾只能硬塞陌生危机 | 当前结果自然使谁产生什么反应或新目标？ |

## 四、选择场景主功能

每章或每个场景素材只选一个主功能，按需附一个次功能：

| 功能编号 | 主功能 | 需要产生的变化 |
|---|---|---|
| P01 | 接住硬钩 | 迫近危险、问题或承诺得到即时处理 |
| P02 | 建立目标 | 人物从被动状态形成可执行诉求 |
| P03 | 获取条件 | 得到行动所需的信息、资源、许可、帮手或技能 |
| P04 | 尝试破局 | 人物用当前方案解决问题，并得到成败结果 |
| P05 | 迫使变策 | 原方案失效，人物必须换方法 |
| P06 | 制造选择 | 两项价值无法兼得，人物表明优先级 |
| P07 | 兑现回报 | 已铺垫的胜负、证据、关系或能力获得可见结果 |
| P08 | 承担后果 | 旧选择的代价到账并改变人物处境 |
| P09 | 推进信息 | 一个问题获得可验证答案或改变解释 |
| P10 | 改变关系 | 信任、戒心、依赖、边界、站位或权力变化 |
| P11 | 展开环境 | 通过人物任务揭示规则、群体、地点或生活方式 |
| P12 | 训练熟练 | 已有能力经尝试、失败和修正获得具体掌握 |
| P13 | 恢复整顿 | 人物处理伤势、损失、情绪或团队状态，并作出决定 |
| P14 | 准备布局 | 为已确认行动取得筹码并建立期待 |
| P15 | 转场抵达 | 因明确需求进入新地点或新场合，首先遭遇差异 |
| P21 | 途中闭环 | 在不抵达目的地、不启动新地图的前提下，完成一次补给、修复、绕路、避险或同行任务并继续上路 |
| P16 | 余波反馈 | 前一结果传播，世界与人物作出反应 |
| P17 | 关系停留 | 通过共同经历深化人物，不强行推进大主线 |
| P18 | 单元收束 | 完成近期承诺，交代结果与余波 |
| P19 | 启动小单元 | 从既有结果或人物欲望形成可持续数章的小目标 |
| P20 | 维持压力 | 不结算长期问题，只让其通过一次具体后果保持存在 |

## 五、选择发散方法

卡点不同，发散方式不同：

### 后果涟漪

适合“上一章已经发生大事，不知道接下来谁动”。

1. 列出直接受益者、受损者、知情者、误判者和旁观者。
2. 分别写出他们最可能的第一动作。
3. 推演该动作给主角制造的局部目标或阻力。
4. 删除需要巧合、越权或新增设定的分支。

### 欲望碰撞

适合“人物很多，但剧情不动”。

1. 写出场内人物各自想得到、保住、隐藏和避免的东西。
2. 找出不能同时满足的两项。
3. 选择谁先行动以及为何现在行动。
4. 让主角以选择回应，而非只听别人安排。

### 策略穷举

适合“目标明确，不知道具体怎么做”。

至少从以下动作中检索：直接争取、交换、试探、欺骗、借力、绕规则、拆小目标、暂退、公开、隐瞒、合作、竞争、牺牲一项、改变目标。

### 更糟变化

适合“冲突太顺或中段乏力”。

不只增加敌人和战力，优先改变：时间、信息、规则、资源、盟友投入、目标含义、环境状态或成功代价。升级必须由已有条件触发。

### 反向结果

适合“候选都太容易预测”。

分别尝试：失败但得线索、成功但付代价、成功过头造成麻烦、失败反而打开别路、双方僵持、双输、主动放弃、第三方获得成果。

### 视角换源

适合“所有点子都由主角发起，世界像不动”。

从对手、盟友、工具人、受害者、管理者、家人或群体的独立利益出发，推演他们合理行动后主角如何被迫选择。

## 六、组合场景素材与路线毛坯

每个场景素材组合以下要素：

`一个场景主功能 + 一个场景原型 + 一个主要阻力 + 一个结果类型`

只有原策略需要改向时才加入转折机制；只需加压时选择升级机制；反应、恢复、日常和关系停留场允许没有显著转折。需要时再加入一个通用套路作为因果骨架，不能同时叠多个主功能和多个大套路。

材料充分时，内部以 6—8 条素材或路线毛坯为发散目标，尽量覆盖 3 种场景原型、3 种阻力来源和 3 种结果类型。存在具备行动条件的配角或群体时，至少两条由其独立利益发起；独行或有限材料不强求。至少保留一条不显著推进长线、只完成局部人物或环境回报的毛坯。

材料有限时，只组合已有事实能承载的要素。缺少人物、规则、资源或关系才能成立的毛坯，标为待挂接并退出正式筛选。以上素材和毛坯都不是正式输出；正式路线必须按确认章数逐章展开。

再按人物合理性、直接承接、局部回报、题材适配、近期新鲜度和未来余量筛出 3—5 条正式路线，并对每条做逐章容量校验；可信路线不足时宁可少给。

## 七、结果类型

结果决定下一步，不必每场都用失败或大反转：

| 编号 | 结果 | 适用效果 |
|---|---|---|
| O01 | 成功 | 当前目标完成，适合兑现或收束 |
| O02 | 成功但付代价 | 有回报，同时留下具体后果 |
| O03 | 成功且超出预期 | 得到过多关注、责任或危险 |
| O04 | 失败 | 目标落空，需要换方法 |
| O05 | 失败且恶化 | 新危机压过原目标 |
| O06 | 失败但有所得 | 获得信息、关系判断或替代入口 |
| O07 | 部分成功 | 只拿到所求的一部分，剩余问题更具体 |
| O08 | 僵持 | 双方都不能继续，形成谈判或时间窗 |
| O09 | 双输 | 冲突双方均失去重要东西，第三方或新秩序受益 |
| O10 | 主动放弃 | 人物以舍弃目标表明优先级并换取别的价值 |
| O11 | 认知改写 | 外在状态少变，但人物对人、事或自身的判断改变 |
| O12 | 关系改写 | 事件结果主要改变信任、边界、站位或依赖 |
| O13 | 建立新常态 | 形成新的生活、工作、训练或合作模式 |
| O14 | 关闭一个选项 | 一条路被证明确实不可行，选择空间收紧 |

结果必须可见，但变化幅度服从作者的近期推进预算。
