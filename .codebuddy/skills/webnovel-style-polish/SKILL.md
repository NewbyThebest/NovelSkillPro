# 文风润色

把已有正文的叙述声音改到 `2-设定/2.4_文风.md` 要求的样子。

由正文写作流程按用户选择调用，也可对任一已有正文单独执行。

## 承载方式

**必须由独立子代理承载，不在写作会话内自行润色。**

- **由写作会话或用户直接调用时**：在写作会话之外拉起独立子代理，把本技能文件、待润色正文、`2-设定/2.4_文风.md`、本章章纲条目位置、本章出场角色档案路径交给它，由它读取本技能文件并执行。**任务书只给这些路径**，不写剧情摘要、改法提示或任何结论性说明；读什么、怎么改由本技能规定。夹带了就把任务书改干净重发。
- **已在独立子代理中运行时**：直接执行，不再向外拉起子代理，不嵌套。

宿主不支持拉起子代理时，告知用户本技能不可执行并停止，不得跳过隔离直接润色。

## 读取范围

只读这六类，**此外任何文件都不读**：

- 本技能文件
- `2-设定/2.4_文风.md`
- 该文件「语料来源」一节指明要读的语料（第 2 步取）
- **本章章纲条目**
- **本章出场角色的档案**：`2-设定/` 下的 `2.3_主要角色设定表.md`、`2.3.1_阶段与功能角色记录.md`，以及角色归档中对应角色的条目（第 5 步读）
- 待润色的那一份正文

除此以外不读任何文件，也不在项目里检索。

## 边界

**不能脱离本章章纲。**

## 执行

按顺序执行，**一步只判该步写明的判断项**，其余判断项留到它自己的步骤，不得提前一并处理。

第 2 至 6 步对应文风文档的判断项：**同一层级的条目合在一步、一次判齐，不同层级不得合并。** 这几步按优先级从低到高排列，优先级越高的要求排得越靠后。文风文档增删判断项时，按同一规则调整对应关系。

## 第 1 步 · 备料

读齐本次润色需要的材料。三类都要读到，次序不限：

- **待润色的正文**。完整读，先只读。
- **本章章纲条目**。长篇取当前十章章纲文件中的对应条目，短篇取 `3-大纲/短篇章纲.md` 中的对应条目。看清本章的剧情骨架、人物选择、结果、伏笔与结尾状态。
- **文风文档** `2-设定/2.4_文风.md`。它是本次润色的唯一依据，完整读。

同时记下**改动前的字数**，后面交付要报变化（`<正文技能目录>` 为 `.agents/skills/webnovel-zhengwen/` 的实际绝对路径）：

```bash
python "<正文技能目录>/scripts/count_chinese_words.py" <章号> "4-正文"
```

读完即进入第 2 步。

## 第 2 步 · 参照作品的文风

核对文风文档「本书要求」第四条「其它部分按参照作品的文风来定」。**本步只判这一项。**

**先取语料**：按文风文档「语料来源」一节写明的取法取料，读几章、怎么挑以那份文件为准。它列的两路都查。

再按下述做法过一遍正文。

1. 重新完整读一遍正文。
2. 以**段落**为单位逐段判：这一段合不合本步这一项要求？段落内部的问题（措辞、句式、视角落点）与段落本身的问题（长短、节奏、该分该合、插话落在哪）一并判。
3. 判完按三种处置改：
   - **合要求的**：原样保留，一个字不动。
   - **不合要求的**：**改写这一段本身**——换句式、换措辞、调断句、并段或拆段、调视角落点。
   - **本步这一项要求而整章缺席的**：补写，按文风文档的要求补上。
4. **除不能脱离章纲这一条外，一律放开手脚改。** 该补的补足，该重写的重写；不要因为"原文也能读"就手下留情。文风文档要求到什么程度，就改到什么程度。

本步做完即进入第 3 步。

- **离人物多远**

1. 重新完整读一遍正文。
2. 以**段落**为单位逐段判：这一段合不合这四项要求？四项一起看，一次判齐。段落内部的问题（措辞、句式、视角落点）与段落本身的问题（长短、节奏、该分该合、插话落在哪）一并判。
3. 判完按三种处置改：

   - **这四项要求而整章缺席的**：补写，按文风文档的要求补上。
4. **除不能脱离章纲这一条外，一律放开手脚改。** 该补的补足，该重写的重写；不要因为"原文也能读"就手下留情。文风文档要求到什么程度，就改到什么程度。

## 第 7 步 · 脚本校准（强制）

**校准脚本只在本步执行。** 前面各步不运行、不试运行、不读脚本文件。（字数统计脚本不受此限，它只在第 1 步与第 8 步运行。）

这是**最后的排版要求，与文风无关**。脚本管的是标点、引号与断行的物理格式；文风管的是叙述声音。前面各步按文风文档改出来的结果，不因脚本调整了排版就算不符合文风，也不必为了迁就排版回头重改文风。

各步改写后重跑一遍正文技能的脚本校准（`<正文技能目录>` 为 `.agents/skills/webnovel-zhengwen/` 的实际绝对路径）：

```bash
python "<正文技能目录>/scripts/check_sentence_linebreaks.py" --fix "<正文路径>"
python "<正文技能目录>/scripts/fix_quotes.py" --fix "<正文路径>"
```

校准完即进入第 8 步。

字数变化用同一脚本再跑一次，与第 1 步记下的数字相减：
